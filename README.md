# Calcolo costi di trasporto

App web installabile (PWA) per stimare in pochi secondi il costo di trasporto delle attrezzature in Italia.
Funziona su telefono, tablet e computer, anche senza connessione. Costo di gestione: zero (GitHub Pages + GitHub Actions).

## Cosa fa
- Menu a tendina per famiglia di prodotto con ricerca immediata per nome o codice.
- Scelta automatica del servizio: pallet o groupage, in base all'imballo di ogni prodotto.
- Carico con più prodotti e quantità, anche colli non a catalogo.
- Destinazione per regione e provincia.
- Servizi: assicurazione all risk, preavviso telefonico, località disagiate.
- Adeguamenti personali: percentuale in più o in meno e adeguamento al prezzo del gasolio (MIMIT). Restano salvati solo sul dispositivo di chi li imposta.
- Riepilogo da condividere (WhatsApp, e-mail), copiare o stampare, con la data dei listini usati.
- Avviso "Aggiorna" quando viene pubblicata una nuova versione.
